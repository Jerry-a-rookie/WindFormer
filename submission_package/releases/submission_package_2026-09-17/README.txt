Applied Soft Computing Elsevier submission project

Compile with pdflatex/bibtex (or latexmk):
  latexmk -pdf main.tex

Before compiling, add references.bib in this folder. The section files contain citation keys from the original IEEE manuscript.
The current main.tex contains the supplied author metadata. Verify the English spelling/transliteration of names and the corresponding-author designation before submission.
All figures are in figures/ and have been renamed to match the \includegraphics paths used by the section files.
